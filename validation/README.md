# Baseline positional-discrepancy figures

These 12 PDFs were preserved from the validated pre-restructure analysis. They
are reference artifacts and are not regenerated by the current pipeline. The
current figures are written to `output/positional_discrepancy/`, which is
intentionally ignored by Git.

## Expected differences

The review-approved current figures intentionally differ from the preserved
baselines in two respects:

- The Figure 9 color legend is titled `Mean PD` rather than
  `Mean Deviation (m)` at the principal investigator's request.
- Current output filenames follow the manuscript/diagnostic naming convention
  documented below; the preserved baseline filenames remain unchanged.

Figure 5 uses an explicit 0-35 m plotting-data restriction so its boxplot
statistics and geometry match the submitted figure without producing a scale
warning. All other labels and visual data patterns were checked against the
baselines.
The regenerated scientific result bundles also match the pre-restructure
results after excluding expected file-path and generation-time metadata.

## Filename mapping

Most baseline names map directly to the corresponding current filename after
removing `_baseline`. Two historical baseline names differ:

- `Figure10_biasPlot_AllBehaviors_baseline.pdf` corresponds to
  `mean_positional_deviation_all_behaviors.pdf`.
- `BiasPlot_BehaviorComparison_baseline.pdf` corresponds to
  `figure_9_mean_positional_deviation_by_behavior.pdf`.
