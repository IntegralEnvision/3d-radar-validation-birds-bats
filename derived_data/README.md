# Derived analysis data

Canonical user-adjustable defaults are centralized in `config/analysis_config.yml`. Analysis-method identifiers remain fixed in code and are stored in each bundle for provenance.

## Positional deviation

The file positional_deviation_results.rds is the single intermediate-data bundle for the positional-deviation analysis. It is generated by scripts/positional_deviation_analysis.R and read by scripts/positional_deviation_figures.R. This entry point is separate from the detection-rate analysis.

The bundle contains:

- schema_version, analysis, and alignment_method provenance fields;
- one named entry per behavior under behaviors;
- paired_data, containing the aligned radar and drone positions;
- rmse, containing flight-level positional-deviation summaries; and
- flight_metadata, containing the registry rows used for that behavior.

The recorded alignment method is approved_common_grid.
Run the complete positional-deviation analysis with:

    Rscript "scripts/positional_deviation_analysis.R"

The radar Y-offset defaults are explicit and adjustable: 20 m for radar 9090 and 0 m for radar 7360. The underlying positional alignment remains the approved common-grid method.

## Detection rate

The file detection_rate_results.rds is the single intermediate-data bundle for the detection-rate analysis. It is generated by scripts/detection_rate_analysis.R and can be read independently by scripts/detection_rate_figures.R.

The bundle contains:

- schema_version, analysis, and opportunity_method provenance fields;
- bin widths, half-bin shift rule, cone-of-silence distance, interpolation step, and projected CRS parameters;
- the 85 flight metadata rows used in the analysis;
- all detection-opportunity bins and flight-level detection summaries;
- gap events and flight-level gap statistics;
- behavior, radar-type, and behavior-by-radar summary tables; and
- analysis failures, unavailable bin options, and availability summaries for quality control.

The recorded opportunity method is complete_drone_coverage_bins. This is intentionally separate from the approved common-grid alignment used by positional deviation.
The canonical detection-rate bundle uses radar-specific defaults: 300 m for radar 9090 and 150 m for radar 7360. Users can override either distance before a full run. For example:

    Rscript "scripts/detection_rate_analysis.R" --cone-9090-meters=325 --cone-7360-meters=175 --results-file=derived_data/detection_rate_results_custom.rds

The uniform 250 m and 300 m bundles are retained as sensitivity artifacts; they are not the canonical radar-specific analysis.
