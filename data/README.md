# Raw data

Raw radar and drone files are not tracked in Git because the local data directory is approximately 10.6 GB and contains files larger than GitHub's 100 MB per-file limit.

To reproduce the analyses, place the data under this directory using the relative paths recorded in `metadata/flights.csv`. The metadata registry is the authoritative manifest for the required radar, drone, and radar-location files.

Before public release, replace this paragraph with the approved data repository DOI, accession, or access-request instructions.
