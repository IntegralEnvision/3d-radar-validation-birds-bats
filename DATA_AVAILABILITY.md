# Data availability

The raw radar and drone data are not included in this Git repository because the complete local dataset is approximately 10.6 GB and includes individual files larger than GitHub's 100 MB limit.

`metadata/flights.csv` provides the relative-path manifest and flight-level configuration needed by the analyses. Reproduction requires arranging the data under `data/` according to that manifest.

**Before public release:** add the manuscript's approved data repository DOI, accession number, or controlled-access instructions here. Do not make the repository public until the authors have confirmed that the raw data and location information may be shared under the selected terms.
